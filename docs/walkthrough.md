# Проверка обязательной версии

Этот документ описывает воспроизводимую проверку текущей реализации. Старые заявления о «100 баллах», офлайн-агенте и готовности всех опций заменены проверяемыми условиями.

## Автоматическая проверка

Из корня проекта:
```powershell
npm ci
npm test
npm run typecheck
npm run build
npm start
```

## Проверка в браузере

1. Открыть http://127.0.0.1:3001 после production-сборки.
2. Проверить пустой набор (0/5), бюджет 100 и отсутствие итогового Score.
3. Загрузить пример ТЗ: 95/100, пять решений, Score56.54, прирост3.99, N_crit0.
4. Запросить анализ. При настроенном рабочем ключе API должен вернуть source=llm; без ключа — явно обозначенный source=rules.
5. Удалить решение: итог не рассчитан, старый анализ помечен устаревшим.
6. Повторно выбрать меру, изменить район, проверить новый расчёт и новый анализ.
7. Проверить блокировку шестой меры, перерасхода, третьей меры направления и конфликтов.
8. Повторить основной проход при ширине375px, проверить отсутствие горизонтальной прокрутки.
9. Проверить отсутствие кнопок экспериментальных опций при выключенном флаге.

# «Аким на 5 часов» — AI-симулятор управления городом (Astana City Management AI Simulator)

AI-симулятор управления городом Астана в роли Акима с ограничением бюджета в 100 условных единиц, принятием 5 управленческих решений, точным математическим движком симуляции Astana Quality of Life Score, AI-агентом аналитики и рекомендаций, интерактивной картой 5 районов, генератором презентаций и сравнением команд.

## User Review Required

> [!IMPORTANT]
> - Проект реализуется на современном стеке **Vite + React + TypeScript + Tailwind/Modern Glassmorphism CSS**, обеспечивающем мгновенный отклик, высочайшую эстетику и 100% воспроизводимость (`npm install`, `npm run dev`, `npm test`).
> - Математический расчет Score полностью детерминирован и на 100% соответствует формулам из ТЗ (включая веса, лаги `(8 - L)/8`, синергии, несовместимости, штрафы $N_{crit}$, базовый Score = 52.56, контрольный набор = 56.5).
> - AI-аналитик работает в двух взаимодополняющих режимах:
>   1. **Встроенный агентный AI-аналитик (Offline / Zero-Config)** — мгновенно выдает глубокий многоуровневый разбор (сильные стороны, скрытые риски, компромиссы, драйверы роста районов и персонализированные рекомендации), не требуя внешних API ключей при проверке жюри.
>   2. **Live LLM Integration (OpenAI / Gemini / Groq / OpenRouter)** — позволяет при желании подключить любой внешний ключ прямо в интерфейсе для живого диалога с виртуальным советником акимата.

## Detailed Requirements Compliance (100 Points)

### 1. Соответствие задаче и работоспособность (25/25)
- Виртуальный бюджет ровно 100 условных единиц.
- 5 направлений: Транспорт, Экология, Соцсфера, Безопасность, Сервисы.
- Ровно 5 решений, не более 2 на одно направление, указание района для районных мер.
- Автоматический контроль превышения и несовместимостей (M1/M3, M4/M7, M5/M13).
- Расчет Score по формуле:
  $$I'_{dk} = \text{clip}\left(I_{dk} + \sum \text{effect}_{m,k} \times \frac{8 - L_m}{8} + \text{synergies}, 0, 100\right)$$
  $$D_d = \sum w_k I'_{dk}$$
  $$D_{avg} = \sum \text{pop}_d D_d$$
  $$\text{Score} = 0.7 \times D_{avg} + 0.3 \times \min(D_d) - 1.0 \times N_{crit}$$
- Точное воспроизведение базового Score (52.56) и эталонного набора M7(Нура)+M8(Нура)+M10(Нура)+M12(Город)+M5(Сарыарка) (Score ≈ 56.5, $N_{crit}=0$).

### 2. Техническая реализация и Agentic AI (25/25)
- Модульная архитектура: разделение математического ядра, валидатора правил, AI-движка и презентационного слоя.
- ИИ не придумывает и не искажает цифры (строго по ТЗ), а получает расчетный контекст и выполняет глубокий многоаспектный анализ:
  - Оценка районных диспропорций (фокус на Нуру/Сарыарку).
  - Выявление неиспользованных синергий (например, M10+M12, M1+M2, M5+M6).
  - Оценка долгосрочных эффектов лага (быстрые меры vs капитальные инфраструктурные).
  - Генерация персональных рекомендаций по улучшению баланса.

### 3. README и воспроизводимость (25/25)
- Четкие инструкции запуска: `npm install`, `npm run dev`, `npm test`.
- Полное описание каждого файла, алгоритмов, формул и структур данных.
- Автоматические тесты (Vitest), покрывающие все сценарии и крайние случаи.

### 4. Ценность и применимость (15/15) + Потенциал и оригинальность (10/10)
- Реализованы все 5 опциональных пунктов из ТЗ:
  1. Сравнение команд и сценариев (A/B сравнение).
  2. Интерактивная карта районов Астаны и радары метрик.
  3. AI-советник по оптимизации (авто-поиск лучших улучшений).
  4. Моделирование неожиданных событий (буран, отопительный кризис).
  5. Генерация готовой презентации отчета Акима за 5 часов.

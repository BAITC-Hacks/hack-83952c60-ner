# План исправлений обязательной версии

Цель: воспроизводимый локальный симулятор по двум документам ТЗ. Сохраняются React/Vite/TypeScript, исходный датасет и математическая формула.

## Реализация

1. Общая runtime-валидация структуры решений и собственных ключей каталога; запрет района у городской меры; nullable Score для невалидного набора.
2. Express API с повторным серверным расчётом и настоящим OpenAI Responses API; ключ только в окружении сервера, модель gpt-4o-mini по умолчанию.
3. Полный вычисленный контекст модели, структурированный ответ, таймаут 20 секунд, явный резервный анализ по правилам.
4. Пустой старт, отдельный контрольный пример, общий валидатор для выбора мер, явный запуск анализа и защита от устаревшего ответа.
5. Карта, аналитика и библиотека сценариев со сравнением входят в основную версию. Кризисы, оптимизатор и презентация скрыты флагом VITE_ENABLE_EXPERIMENTS=false.
6. Команды запуска двух процессов, production-сборка сервера и UI, документация и исключение секретов из Git.
7. Локальное автосохранение черновика и открытого района; независимые именованные снимки пяти допустимых решений. Два версионированных хранилища, runtime-проверка входных данных и работа в памяти при отказе записи.
8. Сравнение пары A/B по текущему движку с разницами B − A: городские показатели, решения, районные оценки и десять индикаторов выбранного района. AI, таймер и кризисы не сохраняются.

## Приёмка

Точные значения: база 52.55768, контрольный набор 56.54307 (95 у.е., N_crit=0). В UI — 52.56 и 56.54. Не подгонять формулу под 56.50.

Проверить все восемь правил, runtime ID, порядок, лаги, синергии, отрицательный эффект, clip и порог 40; API, ошибки и таймаут; смену сценария во время AI-запроса; desktop/mobile; живой ответ source=llm. Автотесты модели используют подставной провайдер.

Актуальные команды и ограничения описаны в README. Итоги фактических проверок — docs/walkthrough.md.

# Карта «Город в разрезе»

Открыть `#/digital-twin` → «Город в разрезе». По умолчанию показан зафиксированный транспортный срез из задания:

| Район | Нагрузка | Изменение к базе |
| --- | --- | --- |
| Сарыарка | 79,6% | −49 |
| Байконур | 128,6% | 0 |
| Алматы | 132,9% | 0 |
| Сарайшык | 132,9% | 0 |
| Есиль | 140,2% | 0 |
| Нура | 152% | 0 |

Переключатель «Текущий сценарий» под картой подключает текущие значения и разницу с базовым сценарием на том же месяце. Остальные слои всегда показывают текущий сценарий. Переключение источника не изменяет состояние модели или сохранения. Панель управления районом под картой явно подписана как текущий сценарий.

## Устройство

- `src/twin/mapData.ts`: исходные условные контуры, неизменяемый срез, цветовые пороги и плотность транспортных агентов.
- `src/twin/CityDistrictMap.tsx`: доступные с клавиатуры HUD-карточки, выбор слоя, настройки и источник данных.
- `src/twin/districtScene.ts`: лениво загружаемая Three.js-сцена с ортографической камерой под углом 45°, стеклянными объёмами, геометрией кварталов, рекой, bloom и транспортом.
- `src/twin/district-map.css`: адаптивная компоновка. На широком экране панели расположены по бокам, на среднем — сверху и снизу, на телефоне — под сценой.

546 декоративных транспортных агентов следуют контурам районов. Сарыарка — 56 агентов, Нура — 112; скорость в Нуре примерно в 3,6 раза ниже. Это визуальная интерпретация нагрузки, не дорожный прогноз. При наведении блок поднимается, загораются соты и пульсирует сеть улиц.

Сцена учитывает `prefers-reduced-motion`, поддерживает паузу, не рисует за пределами экрана или в скрытой вкладке и освобождает WebGL-ресурсы при выходе из режима. Без WebGL сохраняются все данные, выбор районов и упрощённая карта. Числа и логика симулятора не зависят от графического движка.

## Проверка

`npm run build`

`npm test -- tests/district-map.test.tsx tests/twin-ui.test.tsx tests/twin-mandate-ui.test.tsx tests/twin-model.test.ts --testTimeout=20000`

Проверяются точные значения среза, неизменность модели при переключении, пороги 100/140%, соотношение агентов, меню слоёв, fallback, выбор района и сохранение сценариев.

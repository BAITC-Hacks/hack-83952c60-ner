# Транспортный цифровой двойник

Откройте `/#/transport` или вкладку «Транспорт · 3D». Запуск: `npm install`, затем `npm run dev:client`. Если порт 3000 занят: `npm run dev:client -- --port 5175`.

Общая верхняя панель переключает язык (русский, казахский, английский) и светлую/тёмную тему. Подписи 3D-сцены обновляются без сброса движения или камеры; сама сцена сохраняет ночную палитру.

## Управление

- «Текущая ситуация»: час пик, три моста, красный затор центрального узла, 12 км/ч и +48 минут.
- «Новая развязка + выделенный Bus Lane»: за две секунды вырастает голографическая эстакада со съездами; 168 из 420 агентов меняют маршрут, 84 автомобиля становятся пассажирами экспресса. Итог: 44 км/ч, +9 минут, 4 800 агентов/ч, +8.4 AQLS.
- «Приоритет общественного транспорта»: голубые выделенные полосы появляются на трёх существующих мостах, без новой эстакады. Доля общественного транспорта возрастает с 20% до 60% (252 из 420 агентов); пассажирский поток занимает меньше дорожного пространства и получает приоритет движения. Цели: 32 км/ч, +18 минут, 3 960 агентов/ч, +6.8 AQLS.
- «Умные светофоры»: на подходах к существующим мостам появляются согласованные сигналы и движущаяся зелёная волна. Светофорные фазы влияют на скорость агентов у перекрёстков; доля общественного транспорта остаётся 20%, эстакада не строится. Цели: 28 км/ч, +25 минут, 3 240 агентов/ч, +4.6 AQLS.
- Переключатели камеры: общий орбитальный вид и крупный план развязки. Можно вращать, приближать и перемещать карту мышью или касаниями.
- Слои: здания и агенты. Пауза останавливает модель, светофорные фазы и переход; камера остаётся доступной. «Сбросить» восстанавливает исходный детерминированный поток. Переключение между любыми сценариями занимает две секунды и возможно во время предыдущего перехода: новый переход начинается с текущего состояния, агенты сохраняются.

## Интеграция

```tsx
import TransportTwin from './transport/TransportTwin';

export default function Page() {
  return <TransportTwin />;
}
```

Компонент зависит от React, Three.js и lucide-react. Стили изолированы префиксом `tr-`; внешний API и сервер не нужны. Three.js загружается отдельным чанком при открытии режима. Шрифты Manrope и JetBrains Mono используют системные запасные шрифты при отсутствии сети.

- `src/transport/TransportTwin.tsx` — управление и HUD. React получает телеметрию 8 раз в секунду.
- `src/transport/scene.ts` — WebGL-сцена, OrbitControls, геометрия города, шейдер точек, процедурная эстакада, выделенные полосы, сигналы и очистка ресурсов. Контракт `createTransportScene()` возвращает `setOptions`, `updateLanguage`, `reset`, `dispose`. `SceneOptions.scenario` принимает `baseline`, `interchange`, `transit` или `signals`. Телеметрия содержит интерполированные `metrics` и признак `transitioning`.
- `src/transport/simulation.ts` — чистая детерминированная модель без браузерных зависимостей. `createTraffic`, `stepTraffic` и `sampleTrafficAgent` можно подключить к другой визуализации. `SCENARIO_METRICS` содержит иллюстративные цели, `transitWeight` — долю перехода конкретного агента в общественный транспорт, `signalGreen` — согласованные светофорные фазы. `sampleAgent` остаётся доступным для семплирования отдельного маршрута.
- `src/transport/transport.css` — адаптивная оболочка.

Здания используют один InstancedMesh и объединённую геометрию рёбер. Агенты и три точки шлейфа на агента рисуются одним Points / ShaderMaterial. Массивы позиций и цветов переиспользуются. Эффект свечения вычисляется в спрайте без дорогого полноэкранного bloom. DPR ограничен; скрытая вкладка не обновляет модель. При размонтировании освобождаются геометрии, материалы, текстуры, GPU-инстансы, контроллеры и WebGL-контекст.

## Допущения

Это демонстрационная агентная модель и схематичная география, не прогноз трафика Астаны. Затор действительно зависит от нагрузки на подходах к мосту: в исходном сценарии выше порога скорость падает до 10%. Развязка увеличивает вместимость и перераспределяет маршруты; выделенные полосы уменьшают условную нагрузку на дорожное пространство и ускоряют общественный транспорт; умные светофоры изменяют пропускную способность узлов и скорость на подходах в зависимости от фазы. Коэффициенты вместимости, плотности и скорости демонстрационные. Агенты циклически появляются в жилых/деловых кластерах и движутся в обоих направлениях по улицам с короткими кривыми Безье на поворотах.

Числа HUD интерполируются между заданными целями сценариев, а не вычисляются как статистическая оценка реального транспорта. Средняя задержка 48 → 9 минут соответствует снижению на 81%; снижение пиковой задержки на 73% для развязки, 58% для выделенных полос и 42% для светофоров — отдельно заданные показатели. `completed`, нагрузка и заторы получаются из работы агентной модели; они не являются источником целевых чисел HUD. Мини-графики иллюстративны. FPS в подвале измеряется по кадрам; 60 FPS зависит от устройства и браузера.

## Проверка

`npm run typecheck`, `npm run build`, `npm test`. Тесты `tests/transport-model.test.ts` проверяют воспроизводимость, цели и доли потоков всех сценариев, замедление до 10%, приоритет общественного транспорта, влияние светофорных фаз, отсутствие эстакады в двух новых сценариях, прерывание переходов без скачка положения, паузу/сброс и сохранность агентов при длительной симуляции. Отдельная проверка подтверждает, что все три вмешательства меняют фактическое число завершённых маршрутов модели.

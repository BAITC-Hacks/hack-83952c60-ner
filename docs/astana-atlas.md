# Карта Астаны / City Atlas

Маршрут `/#/astana-map` — отдельный GIS-режим. Классический симулятор, цифровой двойник и транспортная демонстрация сохранены. Модуль загружается лениво и не меняет показатели учебной модели.

## Возможности

- Настоящая география OSM на векторной основе OpenFreeMap: улицы, контуры зданий, вода, землепользование и подписи. Тайлы подгружаются по масштабу; карта охватывает город и его окрестности.
- Объёмные здания, 2D/3D, масштабирование, север, обзор области и переходы к Байтереку, старому центру и EXPO.
- Рой жителей включён поверх карты по умолчанию: 1 550 частиц существующей сценарной когорты (1 частица = 1 000 жителей), цвета автомобилей, автобусов и поездок с детьми. Частицы привязаны к географическим линиям улиц из локального снимка OSM и следуют камере в 2D/3D. Доступны скрытие слоя и пауза; при скрытой вкладке и `prefers-reduced-motion` анимация останавливается. Обновление слоя идёт вне React, до 30 раз в секунду.
- Объекты образования и медицины с поиском по имени, типу и улице. Переключатели категорий и поиск одновременно фильтруют точки, плотность и экспорт.
- deck.gl GeoJsonLayer для точек, импортированных геометрий и выделения. ColumnLayer для числа объектов в сетке примерно 500 × 500 м. Высота столбца — условные 65 м на объект, а не высота здания.
- Клик по точке или базовой геометрии открывает исходные свойства. Для инфраструктуры доступна ссылка на объект OSM.
- Локальный импорт GeoJSON FeatureCollection (Point, LineString, Polygon и Multi-варианты) в WGS84; лимиты 20 МБ, 50 000 объектов, 500 000 вершин. Проверяются структура геометрии, координаты и замыкание колец. Рабочая область импорта: 70.8–72.1° E, 50.7–51.6° N.
- Экспорт отфильтрованных объектов инфраструктуры и включённого пользовательского слоя. Базовые векторные тайлы в экспорт не входят. Импортированный файл хранится в памяти до выхода из режима.

## Источники и границы достоверности

Картографическая основа: [OpenFreeMap](https://openfreemap.org/quick_start/), [OpenMapTiles](https://openmaptiles.org/), [© OpenStreetMap contributors, ODbL](https://www.openstreetmap.org/copyright). Атрибуция остаётся на карте.

`public/data/astana-infrastructure.geojson` содержит 500 объектов OSM (340 образования, 160 медицины). Время базы Overpass в полученном ответе — **2026-06-01T08:52:28Z**; время получения отдельно записано в `metadata.fetchedAt`. Это воспроизводимый снимок, не live-реестр. Область запроса: 71.18–71.72° E, 50.98–51.32° N; она не представляет административную границу. У площадных объектов использован центр bounding box, у узлов — исходные координаты.

OSM не гарантирует полноту: объект учреждения может быть отмечен и точкой, и территорией. Количество геообъектов не равно количеству организаций. Высоты зданий из `render_height` могут быть оценочными, без значения используется 8 м. Базовые геометрии при выборе могут быть обрезаны тайлом. Реальные пробки, распределение населения, кадастровые сведения и инженерные сети требуют отдельных источников. Режим представляет географическую основу оцифровки города, а не завершённый официальный цифровой двойник.

Рой — сценарная визуализация, а не наблюдаемые поездки. Численность, виды транспорта и фазы берутся из `ParticleSimulation`; частицы распределяются по улицам детерминированно, с учётом длины и класса дороги. Это не маршрутизация между районами и не соблюдение реальных направлений движения. Схематические заторы исходного симулятора в географический слой не переносятся. Область движения ограничена покрытием транспортного снимка (71.34–71.575° E, 51.02–51.167° N); частицы плавно гаснут на концах отдельных линий. Рой не включается в экспорт GeoJSON инфраструктуры.

## Обновление снимка

```sh
node scripts/refresh-atlas.mjs
```

Скрипт запрашивает публичный Overpass и заменяет снимок только при непустом ответе без `remark`. Результат нужно проверить и включить в следующую сборку. В случае ручного скачивания можно поместить ответ в `public/data/astana-osm-raw.json` и выполнить `node scripts/refresh-atlas.mjs --from-file`; сырой ответ для работы приложения не нужен.

Ключ API не требуется. Базовая карта требует доступа к `tiles.openfreemap.org`; снимок инфраструктуры раздаётся самим приложением. При недоступности WebGL или сети интерфейс сообщает об ошибке и предлагает повтор. Worker MapLibre 6 подключён через `?worker&url`, чтобы Vite собирал его вместе с зависимостями и в dev, и в production.

Проверки: `npm run typecheck`, `npm test`, `npm run build`. Тесты `tests/atlas-data.test.ts` проверяют импорт, координаты, агрегацию и целостность реального снимка.
